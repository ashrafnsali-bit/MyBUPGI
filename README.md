# 🎮 MyBUPGI (Easy FPS) - Web Edition

لعبة تصويب من منظور الشخص الأول (FPS) مثيرة، تم تطويرها باستخدام محرك **Unity**. تتميز اللعبة بتجربة قتال سريعة، ذكاء اصطناعي متطور للأعداء، وواجهة مستخدم عصرية.

### 🚀 [اضغط هنا لتجربة اللعبة مباشرة في المتصفح](https://ashrafns.github.io/MyBUPGI/)

---

## ✨ مميزات اللعبة (Features)
- **نظام قتال متقدم:** يشمل ارتداد الأسلحة (Recoil) ومؤشرات الإصابة (Hit Markers).
- **ذكاء اصطناعي (AI):** أعداء يطاردون اللاعب ويقومون بالهجوم عند الاقتراب.
- **واجهة مستخدم احترافية (Modern UI):** شريط صحة متفاعل، عداد ذخيرة، ومؤشرات لاتجاه الضرر.
- **بيئة لعب محسنة:** إضاءة ومؤثرات بصرية تعزز تجربة اللعب.
- **دعم المنصات:** اللعبة مهيأة للعمل بسلاسة على المتصفحات (WebGL).

## ⌨️ أدوات التحكم (Controls)
- **W, A, S, D**: التحرك في جميع الاتجاهات.
- **Mouse (الماوس)**: تحريك الكاميرا والتصويب.
- **Left Click (الزر الأيسر)**: إطلاق النار.
- **R**: إعادة تعبئة الذخيرة (Reload).
- **Space**: القفز.
- **C**: الانحناء (Crouch).
- **L**: قفل الماوس داخل اللعبة.
